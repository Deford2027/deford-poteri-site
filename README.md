# Дефорд · сколько теряет бизнес без SEO (Беларусь)

Сайт в стилистике deford-studio.ru, собранный по прототипу tema-mail.github.io/deford-poteri/by/.
Структура страниц и блоков, тексты, данные и формулы калькулятора взяты из прототипа.

## Структура (как в прототипе)

| Адрес | Что на странице |
|---|---|
| `/by/` | все ниши: выбор города, общая сумма потерь, 8 сегментов, таблица всех 54 разделов |
| `/by/<сегмент>/` | сегмент: первый экран со счётчиком → разделы → потери по разделам → калькулятор → почему не работает → как работает → поиск против рекламы → доказательства → цена → вопросы → заявка |
| `/by/<сегмент>/<раздел>/` | та же страница, отфильтрованная по одному разделу |
| `/by/<сегмент>/uslugi/` | все услуги сегмента: поиск, таблица потерь, чек правится в строке |

Итого 71 страница: 1 главная + 8 сегментов + 8 страниц «Все услуги» + 54 раздела.

## Папки

- `content/content.json` – тексты страниц, извлечённые из прототипа; `content/data/*.json` – спрос и чеки по сегментам.
- `src/assets/` – стили, скрипты, картинки (иллюстрации и фото – с deford-studio.ru).
- `tools/extract.py` – извлекает тексты и данные из скачанного прототипа.
- `tools/build.py` – собирает сайт в `site/`.
- `site/` – готовый статический сайт, можно выкладывать на любой хостинг.

## Сборка

```
python3 -I tools/build.py                       # собрать site/ из content/ и src/
python3 -m http.server 8790 --directory site    # посмотреть: http://127.0.0.1:8790/by/
```

Обновить тексты и данные из прототипа: скачать страницы в папку (proto_index.html + all/<сегмент>/...)
и запустить `python3 -I tools/extract.py <папка>`, затем `build.py`.

## Что отличается от прототипа

- Убраны служебные части прототипа: панель переключателей, подписи логики блоков, заметки дизайнеру, SEO-панель.
- Город по умолчанию – Минск, выбор запоминается. Автоопределения по IP нет: в прототипе оно шло через
  сторонний сервис ipapi.co, а сам прототип требует на бою определять город только своим сервером.
- Тёмной темы нет (на deford-studio.ru её тоже нет).
- Добавлены хлебные крошки, микроразметка Organization + FAQPage, мобильная панель «Позвонить / Посчитать».

## Нужно уточнить у владельца (в прототипе было «[запросить: …]»)

1. **Куда отправлять заявки.** Формы показывают «Заявка принята», но данные никуда не уходят – подключить в `src/assets/js/site.js`, функция `send()`.
2. Белорусский номер +375 (сейчас стоит +7 953 777-78-91 из прототипа) и часы работы.
3. Цена сайта и ведения в BYN – сейчас «Стоимость рассчитаем под ваши услуги и город».
4. Цена клика в Google Ads и Яндекс Директе по нише – сейчас общая фраза без цифр.
5. Реальный срок выхода в топ – сейчас «назовём после разбора».
6. Кейсы: что можно показать по Evolution Car Service и кейс в каждой нише. Сейчас стоят иллюстрации Дефорд – заменить на скриншоты Метрики.
7. Срок ответа на заявку.
8. Ссылки на политику конфиденциальности и согласие на обработку данных (сейчас `#`).
9. Подтвердить коэффициенты модели на Метрике своих сайтов (`src/assets/js/calc.js`, `MODEL`).
10. Шрифт заголовков: на deford-studio.ru – Tilda Sans (его нет в Google Fonts), здесь близкий Manrope 800. Если есть файлы Tilda Sans – подключить в `style.css`.
